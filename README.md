# Severino Síndicos Profissionais — Website Institucional

Website institucional e comercial de alta conversão para a **Severino Síndicos Profissionais**, especializada em gestão condominial, administração transparente e valorização patrimonial em Cuiabá e Várzea Grande - MT.

## 🚀 Tecnologias
- **HTML5 Semântico** com marcação estruturada Schema.org (`ProfessionalService` e `FAQPage`)
- **CSS3 Puro** (Design System com paleta Midnight Navy, Ouro/Cobre, tipografia Cormorant Garamond e Manrope, micro-animações, layout responsivo)
- **JavaScript Vanilla** (Preloader, menu inteligente com indicador deslizante, simulador de proposta em 4 etapas, integração com WhatsApp e hooks para Google Ads / GA4)

## 📁 Estrutura de Arquivos
```
├── index.html        # Página principal
├── css/
│   └── style.css     # Estilos e design system
├── js/
│   └── main.js       # Interações, animações e conversões
├── assets/
│   └── images/       # Imagens do condomínio, equipe e logotipo
├── favicon.svg       # Ícone do site
├── robots.txt        # Configurações para buscadores
└── sitemap.xml       # Mapa do site para indexação
```
